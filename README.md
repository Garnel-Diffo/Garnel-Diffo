## About Me

I'm an **AI/ML & Full-Stack Engineer** based in Yaoundé, Cameroon 🇨🇲, focused on building systems where applied AI meets real products — visual search engines, recommender systems, computer vision pipelines, and full-stack web & mobile platforms. I like taking a problem from raw data and research all the way to a shipped, reliable interface.

- 🔭 **Currently building:** AI-powered recommender systems and visual search engines
- 🌱 **Currently exploring:** computer vision for assistive & accessibility technology
- 💬 **Ask me about:** Deep Learning, Computer Vision, Recommender Systems, React/Next.js, Django, Flutter
